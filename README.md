Esse projeto é um pong game desenvolvido para a cadeira de Processamento Gráfico, pelos alunos Lucas de Oliveira e Vinícius Aragão do período 2026/02.

Esse pong game tem como objetivo mostrar de forma clara e intuitiva os aprendizados em desenvolvimento de aplicação gráfica em 2d. Além do funcionamento clássico do pong ele também consiste de:
- Modificações no jogo que aplicam translação e escalação (Aumento da bola e duplicação);
- IA inimiga com 3 níveis de dificuldades;
- Sistema de pontuação e reinicialização da partida.
